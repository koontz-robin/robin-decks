Metric Definitions

Because dashboards without definitions are how Gotham gets villains.
Calls: Salesforce Tasks where Type = Call, grouped by CreatedDate.
Contacts: Salesforce call Tasks where CallDisposition starts with Contact, grouped by CreatedDate.
Emails: Salesforce Tasks where Type/TaskSubtype = Email, grouped by CreatedDate.
Discovery Mtgs Set: Salesforce Events Type = 1-Discovery Call, grouped by CreatedDate; Task-subject fallback used only when no Events exist for a rep/month.
Discovery Mtgs Complete: Events Type = 1-Discovery Call with ActivityDate in month, excluding canceled/internal and requiring Completed/Held/Ran if status is populated.
Initial Demos Complete: Events Type = 2-Initial DEMO with ActivityDate in month, excluding canceled/internal and requiring Completed/Held/Ran if status is populated.
Opps Closed: Closed Won Opportunities by CloseDate for AE owners.
MRR Closed: Sum of Salesforce Opportunity Amount for those Closed Won Opportunities.
Avg Deal Size: MRR Closed / Opps Closed.
Avg Cycle Days: Average days from Opportunity CreatedDate to CloseDate for Closed Won Opportunities.
