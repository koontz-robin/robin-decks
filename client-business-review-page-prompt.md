# Rev.io Client Business Review Page Prompt

Use this prompt to generate client-specific GitHub Pages versions of the CBR deck.

```text
Create a polished, client-specific Rev.io Client Business Review GitHub Pages HTML file.

Inputs:
- Client name:
- CBR date:
- Rev.io presenter:
- Client attendees:
- Account background / business update:
- Strategic objectives:
- Products adopted:
- Products not adopted:
- Current metrics:
  - Collections:
  - CDR volume:
  - Invoice volume:
  - Licensee billing:
- Relevant product usage notes:
- Known risks, blockers, or support themes:
- Expansion opportunities:
- Roadmap items relevant to this client:
- Required post-meeting actions:

Build requirements:
- Produce one self-contained HTML page suitable for GitHub Pages.
- Use Rev.io branding: dark navy foundation, Rev.io green accents, clean white content sections, restrained executive styling.
- Make the first viewport a usable CBR cover, not a marketing page.
- Include sticky navigation for Overview, Usage, Metrics, Platform, Roadmap, Actions.
- Show the account story before the product pitch.
- Convert raw metrics into executive scorecards with brief interpretation.
- Show adopted products and not-yet-adopted products as clear visual tiles.
- Connect Rev.io capabilities to client business outcomes.
- Include a post-meeting action plan with owner and timing.
- Keep content source-grounded. Do not invent client facts. Use placeholders or "TBD" where source data is missing.
- Avoid markdown tables in the final HTML. Use responsive CSS grids instead.
- Keep all CSS and JavaScript inline unless the user asks for a multi-file app.

Tone:
- Executive, concise, useful in a live client meeting.
- No generic filler. Every section should help the account team run the review or create a follow-up action.
```
